Ejemplo de Jerarquía de Selectores CSS

1️⃣ Este párrafo usa solo el estilo por etiqueta (gris claro).

2️⃣ Este tiene clase .importante (color cian).

3️⃣ Este tiene ID #aviso (color amarillo).

4️⃣ Este está dentro de un div con ID #contenedor y tiene clase .importante (rosa, porque gana el selector combinado).

5️⃣ Este tiene clase .importante y .forzado con !important (verde, porque el !important gana).

6️⃣ Este tiene un style en línea (rojo, prioridad máxima sin !important).
